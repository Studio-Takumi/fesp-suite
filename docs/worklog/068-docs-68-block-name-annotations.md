# 068 docs: #68 ui-design.pen に独自コンポーネントのブロック名の注釈を付ける

## やったこと

`docs/design/ui-design.pen` の web の iPhone のアートボード14枚に、#13〜#20 で作るブロックの範囲の枠とブロック名のラベルを付けた。色の凡例も置いた。

## 変更したファイル

| ファイル                    | 変更内容                                                        |
| --------------------------- | --------------------------------------------------------------- |
| `docs/design/ui-design.pen` | ルートにグループ「注釈 / ブロック名」を追加（枠・ラベル・凡例） |

## 実装メモ

- 注釈はルートのグループ1つにまとめ、アートボードの子にはしなかった（理由: デザイン本体を汚さず、隠す・消すのがグループ1つで済む）
- ラベルはアートボードの右の余白（幅120px）に置いた（理由: 枠の中に置くとタイトルなどの中身を隠す）
- 色は紫＝#13〜#20 で作る独自コンポーネント、緑＝作成済み（`pageHeader`）、灰＝テキスト系ブロック、橙＝別 Issue・今回は作らない
- 模擬店・出演者の個別ページの上の画像は `coverImage`、店名・出演者名は `shopSummary` / `artistSummary` の扱いとしてラベルに書いた
- iPad のアートボードは #67 で扱うので注釈を付けなかった

## テスト

デザインファイルの変更のみ。

```
bun run format    ✅
bun run lint      ✅
bun run typecheck ✅
bun run test      ✅
bun run build     ✅
```

## 詰まった点

- アートボードのスクリーンショットにはルートの注釈グループが写らない。確認は、アートボードと注釈を一時的なフレームにコピーして撮り、撮ったあと消した

## 残課題

- [ ] `shopSummary` / `artistSummary` の「マップで見る」などのボタンは、デザインでは商品一覧・注意事項より下にある。1ブロックにするとボタンが基本情報の直下に来るので、ボタンを別ブロックに分けるか着手時に決める（#16 / #17）
- [ ] iPad のアートボードの注釈（#67）
