# 098 feat: #98 マップを iPad で左の浮動パネルにする

## やったこと

幅が768px以上のとき、マップのボトムシートと地図の上に浮かぶ検索バーの代わりに、地図の左に浮かぶパネルを
出すようにした。パネルには見出し・検索バー・カテゴリのタブ・場所の一覧が入る。

| ファイル                                                        | 変更内容                                                          |

| `apps/web/src/components/article/blocks/map/MapSidePanel.tsx`   | 追加。左の浮動パネル（見出し・検索バー・タブ・一覧）              |

| `docs/app.md`                                                   | マップの節に「左のパネル」を追加                                  |

## 実装メモ

- **出し分けは `useMediaQuery`。** ボトムシートは開閉の状態とドラッグの仕組みを持っていて、パネルには
  どちらも要らない。CSS で隠すのではなく、描画するものを差し替えた
- **`md` 以上の地図は `main` に敷いた（`md:absolute md:inset-0`）。** 最初は `md:h-full` にしたが、
  `ArticleBody` → `ArticleRenderer` の親に高さが無く、マップの中身は全部絶対配置なので高さが0に潰れて
  画面が真っ白になった。`AppShell` の `main` に `relative` を足し、そこを基準に敷く形にした
- **地図の幅は本文の領域（`max-w-6xl`）まで。** デザインのアートボード（1194px）では画面いっぱいだが、
  本文の幅に収める方がアプリの他の画面と揃う。1194px 幅では左右それぞれ21pxの差
- **見出しはマップのブロックが自前で出す。** デザインではパネルの中に共通パーツの `PageHeader` が
  置かれているが、記事のページ見出し（`pageHeader`）をブロックの中に入れる仕組みは無いので、
  「MAP / マップ」をマップが出す（#98 で相談して決めた）
- **パネルの角丸は16px。** デザインは18pxだが、規約どおり Tailwind のスケールに寄せた
- カテゴリのタブ・場所の一覧はボトムシートとまったく同じものを渡している

## 詰まった点

- **`md:h-full` で地図が高さ0に潰れた。** 親（`ArticleBody` の `article`）に高さが無いので、
  パーセント指定の高さが決まらない。中身が絶対配置だけなので、そのまま何も見えなくなる。
  スクリーンショットを撮って気づいた
