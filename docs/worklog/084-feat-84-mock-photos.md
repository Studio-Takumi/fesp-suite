## 実装メモ

- **写真は `images.unsplash.com` の URL を仮データに入れた**（発注者と合意）。ブログの仮データと同じやり方で、
  本物のデータ（#59 / #60）が入ったら消える。リポジトリに画像ファイルは増やさない
- **写真の URL は、実際に開けるものだけを使っている。** 候補の ID を一つずつ確認し、200 が返るものだけ採用した
- **写真は店・商品の内容に合わせた**（レモネードスタンドは飲み物、クレープ屋はパンケーキ、写真部展示はカメラなど）。
  出演者はライブの写真
- **写真が無いときの見た目は変えていない。** 文化祭Tシャツ（模擬店）・レモンスカッシュ・タオル（商品）・
  出演者1件は写真を入れず、色の枠が出ることを確認できるようにした
- **`ProductList`（商品一覧のブロック）は元から写真に対応していた**ので、仮データを入れただけで写真が出る
- **カードの角丸から写真がはみ出さないよう、商品のサムネに `overflow-hidden` を足した**
