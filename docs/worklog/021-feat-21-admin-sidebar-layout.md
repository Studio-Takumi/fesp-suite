## 実装メモ

- **項目定義は `admin-sidebar.tsx` 内の配列1か所**にまとめた（`navGroups`）。ページが増えたらここに `implemented: true` の項目を足すだけでよい
- **未実装項目は `<Link>` にせず非活性の `<div>`** にした（理由: クリック不可を確実にするため。`aria-disabled` + グレーアウト + 「準備中」バッジ）
- **開閉トグルはデザインに存在しなかったため自分で組んだ**。サイドメニュー内、ナビゲーションとユーザー情報フッターの間に専用行として置いた（理由: テナントのロゴ行やフッターのアバター行は開閉トグルと役割が違うため、混ぜずに独立させた）。折りたたみ時の幅は `w-16`（64px）とし、ラベル・見出し・テナント名・ユーザー名を非表示にしてアイコンだけを残した
- **ハイライト・準備中バッジの色はデザインの変数値がそのまま Tailwind 標準パレット**（`sky-100` / `sky-500` / `slate-*`）と一致したため、独自のCSS変数を追加せずクラス指定で済ませた
- **ハイライト判定はダッシュボード（`/`）のみ完全一致、それ以外は `startsWith`** にした（理由: 今後 `/news/123` のような下位パスができたときに `/news` の項目がハイライトされ続けるようにするため。現状は未実装項目しかないので実質ダッシュボードのみが対象）
