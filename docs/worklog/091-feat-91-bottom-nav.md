# 091 feat: #91 ウェブアプリに下のナビゲーションバーを足す

## やったこと

ウェブアプリの上のヘッダーをやめ、画面の下に貼り付くナビゲーションバー（`BottomNav`）に置き換えた。
ホーム・お知らせ・マップ・スケジュールの4項目を等幅で並べ、いま開いているページの項目を水色にする。
ヘッダーにあった設定への導線は、ホームの「その他のコンテンツ」から張れるように歯車アイコンを足した。

## 実装メモ

- **`fixed` ではなく `sticky bottom-0` にした**（理由: `AppShell` が `min-h-dvh` の縦並びで `main` が `flex-1`
  なので、中身が短くても画面の下に付き、スクロール中も貼り付いたままになる。`fixed` と違って本文と重ならないので、
  `main` に余白を足す必要もない）
- **現在地の判定は `nav-items.ts` の純粋な関数に出した**（理由: `/` は完全一致、それ以外は前方一致という規則を
  1か所に置きたかった。`/news/1` のような個別ページでも「お知らせ」が光る）
- **項目はウェブアプリのコードに定数で持った。** 管理者サイトから編集できるようにするのは #93 に切り出した
  （持ち方・編集画面・API がどれも未定なため、このPRに混ぜると決めごとが多くなりすぎる）
- **項目は「メニュー」ではなく「マップ」にした**（理由: デザインの `BottomNav` は メニュー だが、メニューに当たる
  ページがまだ無い。4項目すべてが既にあるページを指すようにした）
- **ラベルの10px と safe-area の余白だけ任意値を使った**（`text-[10px]` / `pb-[env(safe-area-inset-bottom)]`）。
  どちらも Tailwind のデフォルトスケールで表現できないので、理由をコメントで残してある
- **設定への導線は記事のデータ側で張る。** `contentList` のリンクは記事の props なので、コードでは
  歯車アイコンを選べるようにするところまで。ホームに「設定」のリンクを置くのは管理者サイトでの運用
