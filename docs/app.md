# ウェブアプリ仕様

## 全体レイアウト

- ログインしていないと使えない。ログイン（`/login`）・新規登録（`/signup`）以外のページを未ログインで開くと、`/login?redirect=<開こうとしたパス>` に移動する
- ログイン状態は常に保持する（ブラウザを閉じても残る）
- ヘッダーの右に設定（`/settings`）へのリンクを置く
- ログイン・新規登録のページではヘッダーを出さない

## ページ

### ログイン（`/login`）

- 「Google でログイン」ボタンと、メールアドレス・パスワードの入力欄を置く
- 「Google でログイン」を押すと Google の画面に移動し、戻ってきたらログインした状態になる。初めての Google アカウントなら、その時点でアカウントができる
- 「ログイン」を押したときに、メールアドレスの形式とパスワードが8文字以上かを確かめ、合わなければ入力欄の下にエラーを出す
    - 送信中はボタンを無効にする
    - メールアドレスかパスワードが違うときは「メールアドレスまたはパスワードが違います」、それ以外の失敗は「時間をおいて再度お試しください」と出す
- パスワードの入力欄の目のアイコンで、パスワードの表示・非表示を切り替える
- ログインできたら `redirect` のパスに移動する。`redirect` がない、または `/` で始まるサイト内のパスでない（`//` で始まるものを含む）ときは `/` に移動する
- ログイン済みで開いたときも、同じ規則ですぐに移動する
- 「新規登録」のリンクで `/signup` に移動する。`redirect` は引き継ぐ

### 新規登録（`/signup`）

- 入力欄・入力の確かめ方・移動先の規則はログインと同じ。ボタンは「Google で登録」「登録する」
- パスワードの入力欄の下に「8文字以上で入力してください」と出す
- 「登録する」でアカウントを作り、そのままログインした状態で `redirect` のパスに移動する（メール確認はしない）
- 登録済みのメールアドレスのときは「このメールアドレスは登録済みです」と出す
- 「ログイン」のリンクで `/login` に移動する。`redirect` は引き継ぐ

### 設定（`/settings`）

ログアウトボタンだけの仮ページ。

- 「ログアウト」でログアウトし、`/login` に移動する
- ログアウトしたら、読み込み済みのデータを残さない

### 記事（`/articles/:articleId`）

記事1件のタイトルと本文を表示する画面。本文の描画の仕組みは [`docs/article-system.md`](./article-system.md) を参照。

- 開いたときに `GET /api/articles/:id` で記事を読み込む
- 先頭にタイトルを見出し（`h1`）で出す。タイトルが空の記事は「（無題）」と出す
- 読み込み中はスピナーを出す
- 記事が見つからない（404）ときは「読み込みに失敗しました」「ページが見つかりませんでした」と出す。それ以外のエラーは「読み込みに失敗しました」「時間をおいて再度お試しください」と出す

#### 本文の描画

本文（BlockNoteのブロック配列）を上から順に、ブロックの `type` ごとに次の要素で描画する。

| `type`             | 描画                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| `paragraph`        | 段落。中身が空なら空行として高さを持たせる                                                         |
| `heading`          | 見出し。ページタイトルが `h1` なので1段下げる（レベル1→`h2` … レベル5以上→`h6`）                   |
| `bulletListItem`   | 箇条書き。連続する項目を1つのリストにまとめる                                                      |
| `numberedListItem` | 番号付きリスト。連続する項目を1つのリストにまとめ、先頭項目の `start` から番号を振る               |
| `checkListItem`    | チェックボックス付きの項目。`checked` を反映し、来場者は操作できない                               |
| `toggleListItem`   | 開閉できる項目。初期状態は閉じている。子ブロックを開いた中に出す                                   |
| `quote`            | 引用                                                                                               |
| `divider`          | 区切り線                                                                                           |
| `table`            | 表。`headerRows` 行目まで・`headerCols` 列目までを見出しセルにし、`colspan` / `rowspan` を反映する |
| `codeBlock`        | 等幅フォントのコード。色分けはしない                                                               |

- 子ブロック（`children`）は、そのブロックの下に1段下げて出す
- 文字の装飾は太字・斜体・下線・取り消し線・インラインコードを反映する
- 文字色・背景色・文字の配置（`textColor` / `backgroundColor` / `textAlignment`）と表の列幅は反映しない
- リンクは、URL が `http:` / `https:` / `mailto:` / `tel:` のときだけリンクにする。それ以外は文字だけ出す
    - `http:` / `https:` のリンクは新しいタブで開く

#### 描画できないブロック

- 描画の前に、ブロックを1つずつ記事ドキュメントの形（`articleDocumentSchema`）と照らし合わせる
- 知らない `type` や、形の合わないブロックは、子ブロックごと描画しない。ほかのブロックはそのまま描画を続ける
- 子ブロックだけ形が合わないときは、その子ブロック（とその下）だけを描画しない
