# ウェブアプリ仕様

## 全体レイアウト

- ログインしていないと使えない。ログイン（`/login`）・新規登録（`/signup`）以外のページを未ログインで開くと、`/login?redirect=<開こうとしたパス>` に移動する
- ログイン状態は常に保持する（ブラウザを閉じても残る）
- 画面の上にヘッダーは置かず、下にナビゲーションバーを出す
- 設定（`/settings`）へは、ホームの「その他のコンテンツ」（`contentList`）に置いたリンクから移動する
- 文字は Noto Sans JP で出す。英字のラベル（ページ見出しの英語ラベルなど）は Inter で出す

### 下のナビゲーションバー

主要なページを行き来する導線（デザインの共通パーツ `BottomNav`）。ログイン・新規登録のページでは出さない。

- 画面の下に貼り付け、上に区切り線（`slate-200`）を引く。背景は白。ホームバーぶんの余白（safe-area）を下に足す
- 項目は縦積みでアイコン（lucide、24px）とラベル（10px）。4つを等幅で並べる
- 現在地の項目はアイコン・ラベルともに水色（`sky-500`）、それ以外は薄い灰色（`slate-400`）
- 現在地は、`/` はパスがちょうど一致するときだけ。それ以外は前方一致で、個別ページ（`/news/1` など）でも元の項目を現在地にする

| ラベル       | アイコン        | 移動先      |
| ------------ | --------------- | ----------- |
| ホーム       | `house`         | `/`         |
| お知らせ     | `bell`          | `/news`     |
| マップ       | `map`           | `/map`      |
| スケジュール | `calendar-days` | `/schedule` |

## ページ

### ログイン（`/login`）

- 「Google でログイン」ボタンと、メールアドレス・パスワードの入力欄を置く
- 「Google でログイン」を押すと Google の画面に移動し、戻ってきたらログインした状態になる。初めての Google アカウントなら、その時点でアカウントができる
- 「ログイン」を押したときに、メールアドレスの形式とパスワードが8文字以上かを確かめ、合わなければ入力欄の下にエラーを出す
    - 送信中はボタンを無効にする
    - メールアドレスかパスワードが違うときは「メールアドレスまたはパスワードが違います」、それ以外の失敗は「時間をおいて再度お試しください」と出す
- パスワードの入力欄の目のアイコンで、パスワードの表示・非表示を切り替える
- ログインできたら `redirect` のパスに移動する。`redirect` がない、または `/` で始まるサイト内のパスでない（`//` で始まるものを含む）ときは `/` に移動する
- ログイン済みで開いたときも、同じ規則ですぐに移動する
- 「新規登録」のリンクで `/signup` に移動する。`redirect` は引き継ぐ

### 新規登録（`/signup`）

- 入力欄・入力の確かめ方・移動先の規則はログインと同じ。ボタンは「Google で登録」「登録する」
- パスワードの入力欄の下に「8文字以上で入力してください」と出す
- 「登録する」でアカウントを作り、そのままログインした状態で `redirect` のパスに移動する（メール確認はしない）
- 登録済みのメールアドレスのときは「このメールアドレスは登録済みです」と出す
- 「ログイン」のリンクで `/login` に移動する。`redirect` は引き継ぐ

### 設定（`/settings`）

ログアウトボタンだけの仮ページ。

- 「ログアウト」でログアウトし、`/login` に移動する
- ログアウトしたら、読み込み済みのデータを残さない

### 固定ページ（`/` `/:articleSlug`）

ホーム・お知らせ一覧・スケジュールなどの固定ページ。パスのslugで記事を引き、その本文を表示する。

- 開いたときに `GET /api/articles/slug/:slug` で記事を読み込む。`/` はslugを `home` として読み込む
- `/login`・`/signup`・`/settings`・`/articles/:articleId` は固定ページより先に選ばれる（slugには使えない）
- 本文の描画は記事と同じ（下の「本文の描画」を参照）。ページのタイトルは、本文に置いたページ見出し（`pageHeader`）で出す
- 読み込み中はスピナーを出す
- 記事が見つからない（404）ときは「読み込みに失敗しました」「ページが見つかりませんでした」と出す。それ以外のエラーは「読み込みに失敗しました」「時間をおいて再度お試しください」と出す

パスとページの対応は次のとおり。

| パス        | ページ       |
| ----------- | ------------ |
| `/`         | ホーム       |
| `/news`     | お知らせ一覧 |
| `/blog`     | ブログ一覧   |
| `/schedule` | スケジュール |
| `/map`      | マップ       |
| `/weather`  | 天気         |
| `/shop`     | 模擬店一覧   |
| `/artist`   | 出演者一覧   |

### 個別ページ（`/news/:postId` ほか）

お知らせ・ブログ・模擬店・出演者の1件を表示する仮ページ。パスの識別子は使わず、決まった内容を出す。

| パス                | 出すブロック                                   |
| ------------------- | ---------------------------------------------- |
| `/news/:postId`     | 記事の画像・記事のサマリー・本文・前後の記事   |
| `/blog/:postId`     | 記事の画像・記事のサマリー・本文・関連する記事 |
| `/shop/:shopId`     | 模擬店のサマリー・商品一覧                     |
| `/artist/:artistId` | 出演者のサマリー・セットリスト                 |

### 記事（`/articles/:articleId`）

記事1件の本文を表示する画面。本文の描画の仕組みは [`docs/article-system.md`](./article-system.md) を参照。

- 開いたときに `GET /api/articles/:id` で記事を読み込む
- 記事のタイトルは出さない。ページのタイトルは、本文に置いたページ見出し（`pageHeader`）で出す
- 読み込み中はスピナーを出す
- 記事が見つからない（404）ときは「読み込みに失敗しました」「ページが見つかりませんでした」と出す。それ以外のエラーは「読み込みに失敗しました」「時間をおいて再度お試しください」と出す

#### 本文の描画

本文（BlockNoteのブロック配列）を上から順に、ブロックの `type` ごとに次の要素で描画する。

| ------------------ | -------------------------------------------------------------------------------------------------- |
| `paragraph`        | 段落。中身が空なら空行として高さを持たせる                                                         |
| `heading`          | 見出し。ページ見出しが `h1` なので1段下げる（レベル1→`h2` … レベル5以上→`h6`）                     |
| `bulletListItem`   | 箇条書き。連続する項目を1つのリストにまとめる                                                      |
| `numberedListItem` | 番号付きリスト。連続する項目を1つのリストにまとめ、先頭項目の `start` から番号を振る               |
| `checkListItem`    | チェックボックス付きの項目。`checked` を反映し、来場者は操作できない                               |
| `toggleListItem`   | 開閉できる項目。初期状態は閉じている。子ブロックを開いた中に出す                                   |
| `quote`            | 引用                                                                                               |
| `callout`          | 注意書き。下の「注意書き」を参照                                                                   |
| `divider`          | 区切り線                                                                                           |
| `table`            | 表。`headerRows` 行目まで・`headerCols` 列目までを見出しセルにし、`colspan` / `rowspan` を反映する |
| `codeBlock`        | 等幅フォントのコード。色分けはしない                                                               |
| `pageHeader`       | ページ見出し。下の「ページ見出し」を参照                                                           |
| `scheduleTable`    | スケジュール表。下の「スケジュール表」を参照                                                       |
| `map`              | マップ。下の「マップ」を参照                                                                       |
| `shopList`         | 模擬店一覧。下の「模擬店一覧」を参照                                                               |
| `shopSummary`      | 模擬店のサマリー。下の「模擬店のサマリー」を参照                                                   |
| `productList`      | 商品一覧。下の「商品一覧」を参照                                                                   |
| `artistList`       | 出演者一覧。下の「出演者一覧」を参照                                                               |
| `artistSummary`    | 出演者のサマリー。下の「出演者のサマリー」を参照                                                   |
| `setList`          | セットリスト。下の「セットリスト」を参照                                                           |
| `newsList`         | お知らせ一覧。下の「お知らせ一覧」を参照                                                           |
| `coverImage`       | 記事の画像。下の「記事の画像」を参照                                                               |
| `postSummary`      | 記事のサマリー。下の「記事のサマリー」を参照                                                       |
| `adjacentPosts`    | 前後の記事。下の「前後の記事」を参照                                                               |
| `blogList`         | ブログ一覧。下の「ブログ一覧」を参照                                                               |
| `relatedPosts`     | 関連する記事。下の「関連する記事」を参照                                                           |
| `todayWeather`     | 今日の天気。下の「今日の天気」を参照                                                               |
| `weeklyForecast`   | 週間予報。下の「週間予報」を参照                                                                   |
| `weatherAlert`     | 気象警報・注意報。下の「気象警報・注意報」を参照                                                   |
| `wbgt`             | 暑さ指数。下の「暑さ指数」を参照                                                                   |
| `weatherOverview`  | 天気概況。下の「天気概況」を参照                                                                   |
| `weatherCredit`    | 天気の更新時刻・出典。下の「天気の更新時刻・出典」を参照                                           |
| `mainHero`         | メインスライダー。下の「メインスライダー」を参照                                                   |
| `weatherBar`       | 日付・天気の帯。下の「日付・天気の帯」を参照                                                       |
| `contentList`      | その他のコンテンツ。下の「その他のコンテンツ」を参照                                               |

- 子ブロック（`children`）は、そのブロックの下に1段下げて出す（注意書きは枠の中に出す）
- 文字の装飾は太字・斜体・下線・取り消し線・インラインコードを反映する
- 文字色・背景色・文字の配置（`textColor` / `backgroundColor` / `textAlignment`）と表の列幅は反映しない
- リンクは、URL が `http:` / `https:` / `mailto:` / `tel:` のときだけリンクにする。それ以外は文字だけ出す
    - `http:` / `https:` のリンクは新しいタブで開く

#### 注意書き（`callout`）

読み飛ばされたくない文章を、色付きの枠で囲んで出す（デザインの「注意事項」）。

- 枠の中に、上から見出しの行・本文（ブロックの中身）・子ブロックを出す
    - 見出しの行は、アイコンと種類（`variant`）の表示名を太字で出す。見出しは記事ごとに変えられない
    - 子ブロックは枠の外で1段下げず、本文の下に枠の中で続けて出す
    - 本文が空なら、本文の行を出さない
- 種類ごとの見出し・アイコン・色は次のとおり。枠の背景・枠線・アイコン・文字（見出し・本文・子ブロック）を同じ系統の色にする

| `variant` | 見出し | アイコン         | 色                                                                                         |
| --------- | ------ | ---------------- | ------------------------------------------------------------------------------------------ |
| `info`    | 情報   | `info`           | 緑（背景 `emerald-50` / 枠線 `emerald-300` / アイコン `emerald-700` / 文字 `emerald-800`） |
| `caution` | 注意   | `triangle-alert` | 琥珀（背景 `amber-50` / 枠線 `amber-300` / アイコン `amber-700` / 文字 `amber-800`）       |
| `warning` | 警告   | `octagon-alert`  | 赤（背景 `red-50` / 枠線 `red-300` / アイコン `red-700` / 文字 `red-800`）                 |

#### ページ見出し（`pageHeader`）

各ページの先頭に置く、英語ラベルと日本語タイトルの見出し（デザインの PageHeader）。

- 英語ラベル（`label`）を上に、日本語タイトル（`title`）を下に、`header` の中に出す
    - 英語ラベルは水色（`sky-500`）・太字・字間を広げて、大文字で出す
    - 日本語タイトルは見出し（`h1`）で、大きな文字（`text-3xl`）・太字で出す
- 英語ラベルが空なら、ラベルの行を出さない。日本語タイトルが空なら、タイトルの行を出さない
- 両方とも空なら、ブロックごと出さない

#### スケジュール表（`scheduleTable`）

日付タブ・会場ヘッダー・時間のグリッドで、会場ごとのタイムテーブルを出す（デザインの `web / Schedule / iPhone`）。

- スケジュール（日付 → 会場 → 項目）を読み込む。項目は名前・開始日時・終了日時を持つ
- 読み込み中はスピナーを出す。失敗したら「読み込みに失敗しました」「時間をおいて再度お試しください」と出す
- 日付タブを出すか（`showDateTabs`）が `true` なら、グリッドの上に日付ごとのタブを中央寄せで横に並べる
    - タブには「Day1」「Day2」…（日付の順番）・日付（`M/D`）・曜日（`(土)`）を出す
    - 最初は1日目を選ぶ。タブを押すと、その日のタイムテーブルに切り替える
    - 選んでいるタブは水色（`sky-500`）の塗りに白い文字、ほかのタブはグレー（`slate-100`）の塗りにする
- `false` なら日付タブを出さず、1日目のタイムテーブルを出す
- 会場ヘッダーには、選んだ日の会場名を列ごとに中央寄せで並べ、下に区切り線を引く
- グリッドは縦軸が時間、列が会場
    - 左端に時刻（`H:00`）を、その日の項目の最も早い開始の時（正時）から最も遅い終了の時（正時に切り上げ）まで1時間ごとに出し、時刻ごとに横線を引く
    - 1時間の高さは `h-20`（80px）
- 項目は、会場の列の中に、開始日時から終了日時までの位置・高さで置く
    - 黄色（`amber-400`）の角丸の枠に、名前と時間（`H:mm-H:mm`）を出す。枠に収まらない文字は隠す
    - 押しても何も起きない（リンクにしない）
- 日時は日本時間で出す
- 選んだ日の項目が0件（日付が1つも無いときも）なら、会場ヘッダーとグリッドの代わりに空状態を出す
    - 見出しは「スケジュールはまだありません」、説明は「スケジュールが公開されると、ここに表示されます。」
    - 「再読み込み」を押すと、スケジュールを読み込み直す
    - 日付タブは出したままにする

#### マップ（`map`）

会場のマップを1ページ分出す（デザインの `web / Map / iPhone`）。props は持たない。

- 画面の高さいっぱい（`100dvh`）の枠に、地図の面・検索バー・フロア切替・現在地ボタン・ボトムシートを重ねて出す
- 地図の面は白一色で出す。校舎の図形やピンは出さない
- 場所の一覧・フロアは、表示するときに読み込む

##### 検索バー

- 地図の上端に、虫めがねのアイコン・入力欄（プレースホルダ「場所・模擬店を検索」）・レイヤーのアイコンを横に並べた、丸い白い枠を出す
- 入力した文字で、ボトムシートの場所の一覧を絞り込む（下の「ボトムシート」を参照）
- レイヤーのアイコンは飾りで、押しても何もしない

##### フロア切替

- 検索バーの下の右端に、フロアのボタン（上の階から `3F` / `2F` / `1F`）を縦に並べる
- 開いたときは一番下の階（`1F`）を選んでいる
- ボタンを押すとそのフロアを選んだ状態にする。選んでいるボタンは水色（`sky-500`）の背景に白い文字で出す
- フロアを選んでも、地図の面・場所の一覧は変わらない

##### 現在地ボタン

- フロア切替の下に、現在地のアイコン（水色）の丸い白いボタンを出す
- 押しても何もしない

##### ボトムシート

- 地図の下に重ねて、角の丸い白いシートを出す。上から、ハンドル（灰色の短い横線）・カテゴリのタブ・場所の一覧を並べる
- 開いた状態とたたんだ状態の2段で止まる
    - 開いた状態: シートの高さは画面の半分。場所の一覧まで見える。一覧が長いときは一覧の中だけスクロールする
    - たたんだ状態: ハンドルとカテゴリのタブだけが見える
    - 開いたときは、たたんだ状態
- ハンドルを上下にドラッグすると、指に合わせてシートが動く。離したときに、開いた状態とたたんだ状態の中間より上なら開いた状態、下ならたたんだ状態に止まる
- ハンドルをタップすると、開いた状態とたたんだ状態を切り替える

カテゴリのタブ:

| カテゴリ | アイコン               |
| -------- | ---------------------- |
| ホーム   | 旗                     |
| 食べ物   | ナイフとフォーク       |
| 体験     | ゲームのコントローラー |
| ステージ | 音符                   |

- 丸いアイコンの下にカテゴリ名を出し、4つを横に並べる
- 開いたときは、どのカテゴリも選んでいない
- タブを押すとそのカテゴリを選び、選んでいるタブを押すと選択を外す。選べるカテゴリは1つだけ
- 選んでいるタブは、丸を水色（`sky-500`）の背景に白いアイコンで、カテゴリ名を水色で出す

場所の一覧:

- 場所ごとに、左にサムネ（場所の名前の1文字目を色付きの角丸の枠に出す）、真ん中に上から「開催日（`Day1` など）・団体名」「場所の名前」「`@ <会場>`」、右端に右向きの矢印を出す
- 検索バーの文字とカテゴリの両方に合う場所だけを出す
    - 検索バーの文字は、前後の空白を除いて、場所の名前・団体名・会場のどれかに含まれていれば合う（英字の大文字・小文字は区別しない）。空なら全部合う
    - カテゴリを選んでいなければ、全部合う
- 合う場所が無いときは、一覧の位置に「該当する場所がありません」と出す
- 読み込み中はスピナーを、読み込みに失敗したときは「読み込みに失敗しました」「時間をおいて再度お試しください」を一覧の位置に出す

#### お知らせ一覧（`newsList`）

お知らせを新しい順に並べる一覧（デザインの News一覧・ホームの「お知らせ」）。

- 上にタグのタブ、その下にお知らせの行を並べる
    - タブは、タグタブを出す（`showTagTabs` が `true`）ときに、先頭の「すべて」と、選んだタグ（`tags`）を並べる。選んだタグが1つも無いときは出さない
    - 開いたときは「すべて」を選んでいる。タブを押すと、そのタグが付いたお知らせだけに絞り込む
    - 選んでいるタブは文字を太字にし、下に水色（`sky-500`）の線を引く。タブが画面の幅に収まらないときは横にスクロールする
- 行には、左に日付（月と日）、右に投稿者・タイトル・タグ（`#タグ名`）を出す。行を押すとお知らせ（`/news/:id`）に移動する
- 表示件数（`limit`）があるときは、絞り込んだあとの先頭からその件数だけ出す。無いときは全件出す
- 「すべて見る」を出す（`showViewAll` が `true`）ときは、一覧の下に「すべて見る」ボタンを出す。押すとお知らせ一覧（`/news`）に移動する
- 読み込み中はスピナーを出す。失敗したら「読み込みに失敗しました」「時間をおいて再度お試しください」と出す
- 出すお知らせが0件のときは、行の代わりに一覧の空状態（見出し「お知らせはまだありません」、説明「運営からのお知らせが投稿されると、ここに表示されます。」）を出す。「再読み込み」でお知らせを読み込み直す

#### 記事の画像（`coverImage`）

記事の先頭に出す画像（デザインの News個別の「サムネイル」）。

- 画像の URL（`imageUrl`）の画像を、画面の幅いっぱい・横長（16:9）で出す。はみ出す部分は切り取る
- URL が空なら、ブロックごと出さない

#### 記事のサマリー（`postSummary`）

表示中の記事の作成者・日時・ハッシュタグ（デザインの News個別の「サマリー」）。

- 左に人のアイコン、右に作成者の名前と更新日時（`YYYY年M月D日 HH:mm 更新`。日本時間）を出す
- その下に、記事のタグを `#タグ名` で横に並べる。タグが無ければ、この行を出さない
- 下に区切りの線を引く
- 読み込み中・失敗したときは、お知らせ一覧と同じ

#### 前後の記事（`adjacentPosts`）

表示中の記事の、前の記事・次の記事へのリンク（デザインの News個別の「前後の記事」）。

- 上に区切りの線を引き、「前の記事」（左の矢印・左寄せ）、「次の記事」（右の矢印・右寄せ）の順に、それぞれのタイトルを出す
    - 前の記事は1つ古い記事、次の記事は1つ新しい記事
- 押すとその記事（`/news/:id`）に移動する
- 前の記事・次の記事が無ければ、その行を出さない。両方とも無ければ、ブロックごと出さない
- 読み込み中・失敗したときは、お知らせ一覧と同じ

#### ブログ一覧（`blogList`）

ブログを新しい順に並べる一覧（デザインの Blog一覧）。

- 上にタグのタブ、その下にブログのカードを並べる
    - タブは、タグタブを出す（`showTagTabs` が `true`）ときに、先頭の「すべて」と、選んだタグ（`tags`）を並べる。選んだタグが1つも無いときは出さない
    - 開いたときは「すべて」を選んでいる。タブを押すと、そのタグが付いたブログだけに絞り込む
    - 選んでいるタブは文字を太字にし、下に水色（`sky-500`）の線を引く。タブが画面の幅に収まらないときは横にスクロールする
- カードには、上から角丸のサムネイル（横長・16:9）、日付（`M月D日`）と投稿者、タイトル、抜粋、タグ（`#タグ名` を水色の丸い枠で囲む）を出す。カードを押すとブログ（`/blogs/:id`）に移動する
    - 画像が無ければ、サムネイルの位置にグレーの枠だけを出す
- 読み込み中はスピナーを出す。失敗したら「読み込みに失敗しました」「時間をおいて再度お試しください」と出す
- 出すブログが0件のときは、カードの代わりに一覧の空状態（見出し「ブログはまだありません」、説明「記事が投稿されると、ここに表示されます。」）を出す。「再読み込み」でブログを読み込み直す

#### 関連する記事（`relatedPosts`）

表示中の記事に関連する記事のリスト（デザインの Blog個別の「関連記事」）。

- 上に区切りの線を引き、見出し「関連する記事」を出す
- 記事ごとに、左に角丸のサムネイル（正方形。画像が無ければグレーの枠だけ）、右にタイトルと日付（`M月D日`）を出す
- 押すとその記事（`/blogs/:id`）に移動する
- 関連する記事が0件のときは、ブロックごと出さない
- 読み込み中・失敗したときは、お知らせ一覧と同じ

#### 模擬店一覧（`shopList`）

模擬店を絞り込んで並べる一覧（デザインの `web / Shop一覧 / iPhone`）。

- 上から、日付タブ・検索と並び替え・タグのタブ・模擬店のカードを並べる
- 模擬店（開催日・団体名・店名・場所・開店時刻・閉店時刻・タグ・商品）・タグ・開催日を読み込む
- 読み込み中はスピナーを出す。失敗したら「読み込みに失敗しました」「時間をおいて再度お試しください」と出す
- 日付タブを出す（`showDateTabs` が `true`）ときは、先頭の「すべて」と開催日ごとのタブを横に並べる
    - 開催日のタブには「Day1」「Day2」…（開催日の順番）・日付（`M/D`）・曜日（`(土)`）を出す
    - 開いたときは「すべて」を選んでいる。タブを押すと、その日の模擬店だけに絞り込む
    - 選んでいるタブは水色（`sky-500`）の塗りに白い文字、ほかのタブはグレー（`slate-100`）の塗りにする
- 検索を出す（`showSearch` が `true`）ときは、虫めがねのアイコンと入力欄（プレースホルダ「店名・商品で検索」）を丸い枠で出す
    - 入力した文字は、前後の空白を除いて、店名・団体名・場所・商品名のどれかに含まれていれば合う（英字の大文字・小文字は区別しない）。空なら全部合う
- 並び替えを出す（`showSort` が `true`）ときは、検索の右に並び替えの選択（丸い枠）を出す
    - 選べるのは「おすすめ順」（読み込んだ順）と「名前順」（店名の五十音順）。開いたときは「おすすめ順」
- タグタブを出す（`showTagTabs` が `true`）ときは、先頭の「すべて」と、選んだタグ（`tags`）を並べる。選んだタグが1つも無いときは出さない
    - 開いたときは「すべて」を選んでいる。タブを押すと、そのタグが付いた模擬店だけに絞り込む
    - 選んでいるタブは文字を太字にし、下に水色（`sky-500`）の線を引く。タブが画面の幅に収まらないときは横にスクロールする
- カードは上から次の順に出す。押すと模擬店（`/shops/:id`）に移動する
    - 模擬店の写真を角丸で出す。写真が無ければ、模擬店の色の角丸の枠に、店名の1文字目を白い丸の中に出し、その下に店名を出す
    - 「Dayバッジ（`Day1` など。模擬店の色）・団体名・`@ <場所>`」の行
    - 店名
    - カードに商品を出す（`showProducts` が `true`）ときは、商品のサムネを先頭から3件まで横に並べる。サムネは商品の写真を角丸で出し、左下に価格（`<金額>円`）を重ねる。写真が無ければ、模擬店の色の角丸に商品の並び順の番号を出す
- 絞り込んだ結果が0件のときは、カードの代わりに一覧の空状態（見出し「模擬店が見つかりません」、説明「条件に合う模擬店がありません。絞り込みを変えてお試しください。」）を出す。「再読み込み」で模擬店を読み込み直す
    - 日付タブ・検索・並び替え・タグのタブは出したままにする

#### 模擬店のサマリー（`shopSummary`）

表示中の模擬店の Day・団体・店名・時間・場所と「マップで見る」（デザインの `web / Shop個別 / iPhone` の「ヒーロー」の店名・「基本情報」・「アクション」）。props は持たない。

- 上から、Dayバッジと団体名の行・店名・時間と場所・「マップで見る」ボタンを並べる
- Dayバッジは開催日（`Day1` など）を、模擬店の色の丸い枠に白い文字で出す
- 店名は見出し（`h2`）で、大きな文字（`text-2xl`）・太字で出す
- 時間・場所は、上下に区切りの線を引いた枠の中に、アイコン（時間はタイマー、場所は地図のピン）・ラベル・値の順で横に並べる
    - 時間は `H:mm - H:mm`（日本時間）で出す
- 「マップで見る」は水色（`sky-500`）の丸いボタンで、地図のアイコンとラベルを出す。押すとマップ（`/map`）に移動する
- 読み込み中・失敗したときは、お知らせ一覧と同じ

#### 商品一覧（`productList`）

表示中の模擬店の商品（デザインの `web / Shop個別 / iPhone` の「商品」）。

- 見出し「メニュー」の下に、商品を2列に並べる
- 商品ごとに、正方形の画像・商品名・価格（`<金額>円`）を縦に並べる
    - 画像が無い商品は、模擬店の色の角丸に商品名の1文字目を出す
- 表示する商品（`products`）があるときは、その商品だけを商品の並び順で出す。空なら全件出す
- 出す商品が0件のときは、商品の代わりに一覧の空状態（見出し「商品はまだありません」、説明「商品が登録されると、ここに表示されます。」）を出す。「再読み込み」で商品を読み込み直す
- 読み込み中・失敗したときは、お知らせ一覧と同じ

#### 出演者一覧（`artistList`）

出演者のカードを並べる一覧（デザインの `web / Artist一覧 / iPhone`）。

- 上から、日付タブ・検索と並び替え・タグのタブ・出演者のカードを並べる
- 日付タブを出す（`showDateTabs` が `true`）ときは、先頭の「すべて」と、出演する日（日本時間）を古い順に並べたタブを横に並べる
    - 日付のタブには「Day1」「Day2」…（日付の順番）・日付（`M/D`）・曜日（`(土)`）を出す
    - 開いたときは「すべて」を選んでいる。タブを押すと、その日に出演する出演者だけに絞り込む
    - 選んでいるタブは水色（`sky-500`）の塗りに白い文字、ほかのタブはグレー（`slate-100`）の塗りにする
- 検索を出す（`showSearch` が `true`）ときは、虫めがねのアイコンと入力欄（プレースホルダ「出演者・演目で検索」）を丸い枠に入れて出す
    - 前後の空白を除いた文字が、出演者名・演目・団体名のどれかに含まれる出演者だけに絞り込む（英字の大文字・小文字は区別しない）。空なら全部出す
- 並び替えを出す（`showSort` が `true`）ときは、検索の右に並び替えの選択を出す。「出演順」（出演の早い順）と「名前順」（出演者名の順）から選ぶ。開いたときは「出演順」
- タグのタブを出す（`showTagTabs` が `true`）ときは、先頭の「すべて」と、選んだタグ（`tags`）を並べる。選んだタグが1つも無いときは出さない
    - 開いたときは「すべて」を選んでいる。タブを押すと、そのタグが付いた出演者だけに絞り込む
    - 選んでいるタブは文字を太字にし、下に水色（`sky-500`）の線を引く。タブが画面の幅に収まらないときは横にスクロールする
- カードは上下2つに分ける
    - 上は出演者の写真を角丸で出す。写真が無ければ色付きの角丸の枠にし、中央に出演者名の1文字目を白い丸の中に出し、その下に出演者名・演目を出す。左上に三角の飾りを置く
    - 下は、Day のバッジ（`Day1` など）と団体名、出演者名、出演時間（`H:mm - H:mm`。タイマーのアイコン付き）と会場（ピンのアイコン付き）を出す
    - 色は出演者ごとに紫・緑・水色のどれかを決める（同じ出演者にはいつも同じ色）。写真が無いときの枠の背景・三角・1文字目と、Day のバッジを同じ系統の色にする
- カードを押すと出演者（`/artists/:id`）に移動する
- 絞り込みは、日付・検索の文字・タグのすべてに合う出演者だけを出す
- 読み込み中はスピナーを出す。失敗したら「読み込みに失敗しました」「時間をおいて再度お試しください」と出す
- 出す出演者が0件のときは、カードの代わりに一覧の空状態（見出し「出演者はまだありません」、説明「出演者が公開されると、ここに表示されます。」）を出す。「再読み込み」で出演者を読み込み直す

#### 出演者のサマリー（`artistSummary`）

表示中の出演者の基本情報と、スケジュール・マップへのボタン（デザインの `web / Artist個別 / iPhone` の「ヒーロー」の出演者名・演目、「基本情報」・「アクション」）。

- 上に Day のバッジ（`Day1` など）と団体名を横に並べ、その下に出演者名（`h1`）、その下に演目を出す
    - Day のバッジの色は、出演者一覧のカードと同じ規則で決める
- その下に上下を線で区切った枠を作り、「出演」（`N日目 H:mm - H:mm`。日本時間）・「会場」・「人数」（`N名`）を、アイコン・ラベル・値の順に1行ずつ並べる
- その下に「スケジュールで見る」（水色（`sky-500`）の塗りに白い文字・カレンダーのアイコン）と「会場をマップで見る」（グレー（`slate-100`）の塗り・マップのアイコン）のボタンを縦に並べる
    - 「スケジュールで見る」はスケジュールのページ（`/schedule`）、「会場をマップで見る」はマップのページ（`/map`）に移動する
- 読み込み中・失敗したときは、お知らせ一覧と同じ

#### セットリスト（`setList`）

表示中の出演者のセットリスト（デザインの `web / Artist個別 / iPhone` の「セットリスト」）。

- 見出し（`h2`）「セットリスト」の下に、曲を上から順に並べる
- 曲ごとに、左に順番の番号を色付きの丸の中に出し、右に曲名と原曲のアーティスト名を出す。曲の間に区切りの線を引く（最後の曲の下には引かない）
    - 丸の色は、出演者一覧のカードと同じ規則で決める
- 曲が1曲も無いときは、ブロックごと出さない
- 読み込み中・失敗したときは、お知らせ一覧と同じ

#### 一覧の空状態

一覧に出すものが0件のときに、一覧の代わりに出す表示（デザインの「状態: 空」）。どの一覧でも同じ見た目にする。

- 上から、受信箱のアイコン（薄いグレーの丸の中）、見出し、説明、「再読み込み」ボタンを中央に並べる
- 見出し・説明の文言は一覧ごとに決める
- 「再読み込み」を押すと、その一覧を読み込み直す

#### 天気のブロック

今日の天気・週間予報・気象警報・注意報・暑さ指数・天気概況・天気の更新時刻・出典の6つ（デザインの `web / Weather / iPhone`）。
どれも props を持たず、天気のデータを読んで出す。

- 6つのブロックは同じ天気のデータを読む。同じページに複数置いても、読み込みは1回にまとめる
- 読み込み中と、読み込みに失敗したときは、ブロックごと出さない
- 気温は「°」付きの整数、降水確率は「%」付きの整数で出す
- 天気は次のアイコンで出す

| 天気           | アイコン                     |
| -------------- | ---------------------------- |
| 晴れ           | 太陽（黄色 `amber-400`）     |
| 晴れ時々くもり | 雲と太陽（黄色 `amber-400`） |
| くもり         | 雲（グレー `slate-400`）     |
| 雨             | 雨雲（水色 `sky-500`）       |

#### 今日の天気（`todayWeather`）

- 水色（`sky-50`）の角丸の枠の中に、左に天気のアイコン（大）、右に気温を出す
- 気温は、現在の気温を大きな細い文字で「23°C」と出し、その下に「最高 25°」（赤 `rose-500`）・「最低 18°」（水色 `sky-500`）・「降水 40%」を横に並べる

#### 週間予報（`weeklyForecast`）

- 見出し（`h2`）「週間予報」の下に、1日1枚のカードを横に並べる。画面に収まらない分は横にスクロールする
- カードには上から、日付・天気のアイコン・最高気温（赤 `rose-500`）と最低気温（水色 `sky-500`）・降水確率を出す
    - 日付は、今日なら「今日」、明日なら「明日」、それ以外は「15(土)」の形で出す（日本時間）
- 予報が1日も無いときは、ブロックごと出さない

#### 気象警報・注意報（`weatherAlert`）

- 発表中の警報・注意報があるときだけ出す。無いときは、ブロックごと出さない
- 薄い赤（`red-50`・枠線 `red-200`）の角丸の枠の中に、注意のアイコンと、発表中の警報・注意報の種類（「暴風」など）のチップを横に並べる
    - 警報のチップは赤（`rose-500`）に白い文字、注意報のチップは黄色（`amber-400`）に黒い文字で出す
- チップの下に、気象台の解説の文章を出す

#### 暑さ指数（`wbgt`）

- グレー（`slate-50`）の角丸の枠の中に、「暑さ指数（WBGT）」と、暑さ指数の値・段階・一言を出す
    - 値と段階は、段階の色で出す。一言は右に薄い文字で出す
- その下に、5つの段階の色の帯と、段階ごとの範囲・名前を横に並べる

| 段階     | 範囲         | 色                       | 一言                         |
| -------- | ------------ | ------------------------ | ---------------------------- |
| 注意     | 25未満       | 水色（`sky-400`）        | 積極的に水分補給を           |
| 警戒     | 25以上28未満 | 黄色（`amber-400`）      | 運動時は積極的に休憩を       |
| 厳重警戒 | 28以上31未満 | オレンジ（`orange-400`） | 激しい運動は避けましょう     |
| 危険     | 31以上33未満 | 赤（`rose-500`）         | 運動は原則中止しましょう     |
| アラート | 33以上       | 紫（`violet-400`）       | 不要不急の外出は避けましょう |

#### 天気概況（`weatherOverview`）

- 見出し（`h2`）「今日の天気概況」の下に、気象台の天気概況の文章を出す。文章の改行はそのまま出す
- 文章が空なら、ブロックごと出さない

#### 天気の更新時刻・出典（`weatherCredit`）

- 上に区切りの線を引き、更新のアイコンと「11:10 更新 ・ 出典: 気象庁」（更新時刻は日本時間の `HH:mm`）を小さな薄い文字で出す

#### メインスライダー（`mainHero`）

ホームの一番上に出す画像のスライダー（デザインの `web / Home / iPhone` の「メインスライダー」）。

- 画面の幅いっぱい・横長の枠に、選んでいるスライドの画像を出す。はみ出す部分は切り取る
- 画像の下側に、下ほど濃い黒の影を重ね、その上に上から順にキャッチ・タイトル・ドットを出す
    - キャッチは小さな白い文字で、字間を広げて出す。タイトルは大きな白い太字で出す
    - キャッチ・タイトルが空なら、その行を出さない
- ドットはスライドの数だけ横に並べ、押すとそのスライドに切り替える
    - 選んでいるドットは白い横長の丸、ほかのドットは白い半透明の丸で出す
    - スライドが1枚のときは、ドットを出さない
- 自動では切り替えない。スワイプでも切り替えない
- スライド（`slides`）は、1行に1枚を `画像の URL|キャッチ|タイトル` の形で並べた文字列で持つ
    - 画像の URL は `http://` か `https://` で始まる URL、キャッチは30文字まで、タイトルは40文字まで
- 出すスライドが1枚も無いときは、ブロックごと出さない

#### 日付・天気の帯（`weatherBar`）

今日の日付と天気を1行で出す帯（デザインの `web / Home / iPhone` の「日付・天気」）。props は持たない。

- 画面の幅いっぱいの帯にし、下に区切りの線を引く
- 左に日付、真ん中に天気、右に右向きの矢印を出す
    - 日付は月日（`M/D`）を大きな文字で、曜日（`(土)`）を小さな薄い文字で出す
    - 天気は天気のアイコンと、最高気温（赤 `rose-500`）・`/`・最低気温（水色 `sky-500`）を出す
- 帯を押すと天気（`/weather`）に移動する
- 天気のデータと天気のアイコンは「天気のブロック」と同じものを読む。読み込み中と、読み込みに失敗したときは、ブロックごと出さない

#### その他のコンテンツ（`contentList`）

各ページへのリンクを並べるグリッド（デザインの `web / Home / iPhone` の「その他のコンテンツ」）。

- 見出し（`h2`）「その他のコンテンツ」の下に、リンクを2列のグリッドで並べる
- リンクは、グレー（`slate-50`）の角丸の枠に、アイコン（水色 `sky-500`）と表示名を横に並べて出す。押すとリンク先に移動する
- リンク（`links`）は、1行に1件を `表示名|アイコン|リンク先` の形で並べた文字列で持つ
    - 表示名は20文字まで
    - アイコンは次の8つから選ぶ
    - リンク先は `/` で始まるページのパスか、`http://` `https://` で始まる URL
- 出すリンクが1件も無いときは、ブロックごと出さない

| アイコン       | 値               |
| -------------- | ---------------- |
| カレンダー     | `calendar-days`  |
| 地図           | `map`            |
| 店             | `store`          |
| 音符           | `music`          |
| 新聞           | `newspaper`      |
| 雲と太陽       | `cloud-sun`      |
| クリップボード | `clipboard-list` |
| 歯車           | `settings`       |

#### 描画できないブロック

- 描画の前に、ブロックを1つずつ記事ドキュメントの形（`articleDocumentSchema`）と照らし合わせる
- 知らない `type` や、形の合わないブロックは、子ブロックごと描画しない。ほかのブロックはそのまま描画を続ける
- 子ブロックだけ形が合わないときは、その子ブロック（とその下）だけを描画しない
