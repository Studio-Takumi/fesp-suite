# API仕様

## 記事（articles）

### 記事オブジェクト

| フィールド          | 型               | 説明                                                                  |
| ------------------- | ---------------- | --------------------------------------------------------------------- |
| `id`                | `uuid`           | 記事ID                                                                |
| `event_id`          | `uuid`           | 所属するイベント                                                      |
| `slug`              | `string \| null` | ウェブアプリのパス（`/news` なら `news`）。持たない記事は `null`      |
| `created_by`        | `uuid`           | 作成したユーザー                                                      |
| `creator`           | `object`         | 作成したユーザーの情報（下表）                                        |
| `title`             | `string`         | タイトル。100文字まで。空文字のこともある                             |
| `content`           | `array`          | BlockNoteのブロック配列（`articleDocumentSchema`）                    |
| `status`            | `string`         | 公開状態。`draft`（下書き）/ `published`（公開）                      |
| `published_version` | `number \| null` | 公開中の版の番号。下書きなら `null`                                   |
| `published_at`      | `string \| null` | 初めて公開した日時。以降は変わらない。一度も公開していなければ `null` |
| `created_at`        | `string`         | 作成日時                                                              |
| `updated_at`        | `string`         | 更新日時                                                              |
| `latest_history`    | `object \| null` | 最新の版（下表）。読めなければ `null`（下記）                         |
| `schedule`          | `object \| null` | 予約（下表）。予約が無い、またはイベントの `staff` でなければ `null`  |
| `tags`              | `array`          | 付いているタグ（下表）。付いていなければ空配列                        |

`title` / `content` は、公開中の記事なら公開している中身、下書きなら最新の版の中身。
公開中の記事を一時保存した変更（`PUT /api/articles/:id`）は、公開に反映するまで `latest_history` にだけ入る。

`latest_history` は、イベントの `staff` には常に返す。それ以外のメンバーには、最新の版が公開中の版のときだけ返し、それ以外は `null` を返す（公開していない版は見せない）。

一覧では本文を返さないため、`content` と `latest_history` を除いた形になる。

#### `creator`

| フィールド     | 型               | 説明                      |
| -------------- | ---------------- | ------------------------- |
| `display_name` | `string \| null` | 表示名。未設定なら `null` |

#### `latest_history`

| フィールド   | 型             | 説明                                    |
| ------------ | -------------- | --------------------------------------- |
| `version`    | `number`       | 版の番号。記事ごとに1から増える         |
| `title`      | `string`       | その版のタイトル                        |
| `content`    | `array`        | その版の本文（`articleDocumentSchema`） |
| `created_by` | `uuid \| null` | その版を保存したユーザー                |
| `created_at` | `string`       | 版を作った日時                          |
| `updated_at` | `string`       | 版を最後に上書きした日時                |

#### `tags`

タグ1件ごとに次の形。並びは `tags` の `sort_order` の順。

| フィールド | 型       | 説明       |
| ---------- | -------- | ---------- |
| `id`       | `uuid`   | タグID     |
| `name`     | `string` | タグの名前 |

#### `schedule`

| フィールド   | 型             | 説明                       |
| ------------ | -------------- | -------------------------- |
| `version`    | `number`       | 公開する版の番号           |
| `publish_at` | `string`       | 公開する日時               |
| `created_by` | `uuid \| null` | 予約したユーザー           |
| `created_at` | `string`       | 予約した日時               |
| `updated_at` | `string`       | 予約を最後に上書きした日時 |

予約の仕組みは `PUT /api/articles/:id/schedule` を参照。

### `GET /api/articles`

イベントの記事一覧。`updated_at` の新しい順。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### クエリ

| 名前       | 型       | 必須 | 説明                |
| ---------- | -------- | ---- | ------------------- |
| `event_id` | `uuid`   | ✅   | 対象のイベント      |
| `limit`    | `number` |      | 1〜100。既定値 `20` |
| `offset`   | `number` |      | 0以上。既定値 `0`   |

#### レスポンス（`200`）

```json
{
    "items": [
        {
            "id": "7f1c2a9e-3b4d-4e5f-8a6b-1c2d3e4f5a6b",
            "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
            "created_by": "3c9d1e2f-4a5b-4c6d-8e7f-9a0b1c2d3e4f",
            "creator": { "display_name": "山田太郎" },
            "title": "模擬店のお知らせ",
            "status": "published",
            "published_version": 1,
            "published_at": "2026-09-14T12:00:00+09:00",
            "created_at": "2026-09-14T10:00:00+09:00",
            "updated_at": "2026-09-14T12:30:00+09:00",
            "schedule": null
        }
    ],
    "limit": 20,
    "offset": 0
}
```

イベントの `staff` には下書きを含むすべての記事を、それ以外のメンバーには公開済み（`status` が `published`）の記事だけを返す。イベントが存在しないとき、所属していないときも `items` が空の `200` を返す。

#### エラー

| ステータス | `code`         | 条件                                                 |
| ---------- | -------------- | ---------------------------------------------------- |
| `400`      | `bad_request`  | クエリが不正                                         |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効 |

### `GET /api/articles/:id`

記事を1件、本文つきで取得する。イベントの `staff` は下書きも読める。それ以外のメンバーは公開済み（`status` が `published`）の記事だけ読める。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### パス

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| `id` | `uuid` | ✅   | 記事ID |

#### レスポンス（`200`）

```json
{
    "id": "7f1c2a9e-3b4d-4e5f-8a6b-1c2d3e4f5a6b",
    "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
    "slug": null,
    "created_by": "3c9d1e2f-4a5b-4c6d-8e7f-9a0b1c2d3e4f",
    "creator": { "display_name": "山田太郎" },
    "title": "模擬店のお知らせ",
    "content": [
        {
            "id": "a1",
            "type": "paragraph",
            "props": { "backgroundColor": "default", "textColor": "default", "textAlignment": "left" },
            "content": [{ "type": "text", "text": "現金のみです。", "styles": {} }],
            "children": []
        }
    ],
    "status": "published",
    "published_version": 2,
    "published_at": "2026-09-14T12:00:00+09:00",
    "created_at": "2026-09-14T10:00:00+09:00",
    "updated_at": "2026-09-14T12:30:00+09:00",
    "latest_history": {
        "version": 3,
        "title": "模擬店のお知らせ（2日目）",
        "content": [],
        "created_by": "3c9d1e2f-4a5b-4c6d-8e7f-9a0b1c2d3e4f",
        "created_at": "2026-09-14T13:00:00+09:00",
        "updated_at": "2026-09-14T13:10:00+09:00"
    },
    "schedule": null
}
```

例は、版2を公開したあとに版3を一時保存した記事。`staff` でないメンバーには、版3は公開していないので `latest_history` を `null` で返す。

#### エラー

| ステータス | `code`         | 条件                                                                                                                            |
| ---------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `400`      | `bad_request`  | `id` の形式が不正                                                                                                               |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効                                                                            |
| `404`      | `not_found`    | 記事が存在しない、所属していないイベントの記事、または `staff` でないメンバーが下書きを開いた（下書きがあること自体を伝えない） |

読める範囲は `GET /api/articles/:id` と同じ。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### パス

| 名前   | 型       | 必須 | 説明                                                 |
| ------ | -------- | ---- | ---------------------------------------------------- |
| `slug` | `string` | ✅   | 記事のslug。ホームなら `home`（形式は `docs/db.md`） |

#### クエリ

| 名前       | 型     | 必須 | 説明           |
| ---------- | ------ | ---- | -------------- |
| `event_id` | `uuid` | ✅   | 対象のイベント |

#### レスポンス（`200`）

記事オブジェクト。形は `GET /api/articles/:id` と同じ。

#### エラー

| ステータス | `code`         | 条件                                                                                                                                      |
| ---------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `400`      | `bad_request`  | `slug` の形式が不正、または `event_id` がない・形式が不正                                                                                 |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効                                                                                      |
| `404`      | `not_found`    | そのslugの記事が存在しない、所属していないイベントの記事、または `staff` でないメンバーが下書きを開いた（下書きがあること自体を伝えない） |

### `POST /api/articles`

記事を作成する。そのイベントの `staff` だけが作れる。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### リクエストボディ

```json
{
    "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
    "title": "模擬店のお知らせ",
    "content": []
}
```

| フィールド | 型       | 必須 | 説明                                                         |
| ---------- | -------- | ---- | ------------------------------------------------------------ |
| `event_id` | `uuid`   | ✅   | 対象のイベント                                               |
| `title`    | `string` | ✅   | タイトル。前後の空白を取り除いたうえで100文字まで。空文字可  |
| `content`  | `array`  | ✅   | BlockNoteのブロック配列（`articleDocumentSchema`）。空配列可 |

作成者（`created_by`）はリクエストしたユーザーになる。記事は下書き（`status` が `draft`）で作られる。どちらもボディでは指定できない。
作成したタイトル・本文で版1（`latest_history`）ができる。

#### レスポンス（`201`）

作成した記事オブジェクト（`GET /api/articles/:id` と同じ形）。

#### エラー

| ステータス | `code`         | 条件                                                                                                 |
| ---------- | -------------- | ---------------------------------------------------------------------------------------------------- |
| `400`      | `bad_request`  | `event_id` の形式が不正、`title` が100文字を超える、または `content` が記事ドキュメントの形でない    |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効                                                 |
| `403`      | `forbidden`    | そのイベントの `staff` でない（`visitor`、所属していない、イベントが存在しない、のいずれも同じ扱い） |

### `PUT /api/articles/:id`

記事を保存する。保存のたびにタイトル・本文を版として残し、`status` に応じて公開中の中身を更新する。記事のイベントの `staff` だけが保存できる。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### パス

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| `id` | `uuid` | ✅   | 記事ID |

#### リクエストボディ

```json
{
    "title": "模擬店のお知らせ",
    "content": [],
    "status": "published"
}
```

| フィールド | 型       | 必須 | 説明                                                                                   |
| ---------- | -------- | ---- | -------------------------------------------------------------------------------------- |
| `title`    | `string` | ✅   | タイトル。前後の空白を取り除いたうえで100文字まで。空文字可                            |
| `content`  | `array`  | ✅   | BlockNoteのブロック配列（`articleDocumentSchema`）。空配列可                           |
| `status`   | `string` |      | 保存後の公開状態。`draft`（下書き）/ `published`（公開）。省略すると公開状態を変えない |

#### 版の残し方

保存するたびに、タイトル・本文を記事の版として残す。版は一直線に増える。

- タイトル・本文が最新の版と同じなら、版は増やさない
- 次をすべて満たすときは、新しい版を足さずに最新の版を上書きする
    - 最新の版を保存したのが、リクエストしたユーザー
    - 最新の版を作ってから30分以内
    - 最新の版が公開中の版（`published_version`）ではない
    - 最新の版が予約中の版（`schedule.version`）ではない
- それ以外は、新しい版を足す

#### 公開状態

| `status`    | 下書きの記事                                                                   | 公開中の記事                                                                         |
| ----------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 省略        | `title` / `content` を今回の中身にする                                         | 変えない（一時保存。変更は `latest_history` にだけ入る）                             |
| `published` | `title` / `content` を今回の中身にして公開する。`published_version` は今回の版 | `title` / `content` を今回の中身にする（公開に反映）。`published_version` は今回の版 |
| `draft`     | `title` / `content` を今回の中身にする                                         | `title` / `content` を今回の中身にして下書きに戻す。`published_version` は `null`    |

保存のたびに `updated_at` が現在時刻になる（一時保存でも、中身が変わっていなくても）。
記事のイベント（`event_id`）と作成者（`created_by`）は変えられない。
公開日時（`published_at`）は初めて `published` にしたときの現在時刻になり、以降は下書きに戻しても、公開し直しても変わらない。ボディでは指定できない。
`published_version` が変わったとき（公開する・公開に反映して版が変わる・下書きに戻す）は、記事の予約を取り消す。

#### レスポンス（`200`）

保存後の記事オブジェクト（`GET /api/articles/:id` と同じ形）。

#### エラー

| ステータス | `code`         | 条件                                                                                                                                              |
| ---------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `400`      | `bad_request`  | `id` の形式が不正、`title` が100文字を超える、`content` が記事ドキュメントの形でない、または `status` を指定していて `draft` / `published` でない |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効                                                                                              |
| `403`      | `forbidden`    | 記事のイベントのメンバーだが `staff` でない                                                                                                       |
| `404`      | `not_found`    | 記事が存在しない、所属していないイベントの記事、または `staff` でないメンバーが下書きを更新しようとした                                           |

### `PUT /api/articles/:id/schedule`

記事の版を、指定した日時に公開するよう予約する。すでに予約があれば上書きする。記事のイベントの `staff` だけが予約できる。
下書きの記事なら公開の予約、公開中の記事なら公開中の中身を差し替える予約になる。

**お知らせ・ブログ・模擬店・出演者の予約もこのエンドポイントを使う。** サマリーごとに予約のエンドポイントは作らない。
予約は記事の公開状態を動かすだけで、サマリーの種類によって変わらないため。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### パス

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| `id` | `uuid` | ✅   | 記事ID |

#### リクエストボディ

```json
{
    "version": 3,
    "version_updated_at": "2026-09-14T04:10:00.123456+00:00",
    "publish_at": "2026-09-20T09:00:00+09:00"
}
```

| フィールド           | 型       | 必須 | 説明                                                                                  |
| -------------------- | -------- | ---- | ------------------------------------------------------------------------------------- |
| `version`            | `number` | ✅   | 公開する版の番号                                                                      |
| `version_updated_at` | `string` | ✅   | その版の `updated_at`。読み込んだ値（`latest_history.updated_at` など）をそのまま送る |
| `publish_at`         | `string` | ✅   | 公開する日時。オフセット付きの ISO 8601。現在より後                                   |

#### 時間が来たとき

- 1分ごとに、`publish_at` を過ぎた予約の版を記事の公開中の版（`published_version`）にし、予約を消す（最大で1分ほど遅れる）
- 初めての公開なら、`published_at` は `publish_at` になる
- 予約した版のあとに保存した変更は、公開されない（`latest_history` に残る）

#### 予約が消えるとき

- 取り消した（`DELETE /api/articles/:id/schedule`）
- 時間が来て公開した
- `PUT /api/articles/:id` で `published_version` が変わった（公開する・公開に反映して版が変わる・下書きに戻す）。一時保存では消えない

予約中の版は、`PUT /api/articles/:id` で上書きされない（新しい版が足される）。

#### レスポンス（`200`）

予約後の記事オブジェクト（`GET /api/articles/:id` と同じ形）。

#### エラー

| ステータス | `code`         | 条件                                                                                                                                     |
| ---------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `400`      | `bad_request`  | `id` の形式が不正、`version` が1以上の整数でない、`version_updated_at` / `publish_at` が日時の形式でない、または `publish_at` が現在以前 |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効                                                                                     |
| `403`      | `forbidden`    | 記事のイベントのメンバーだが `staff` でない                                                                                              |
| `404`      | `not_found`    | 記事が存在しない、所属していないイベントの記事、または `staff` でないメンバーが下書きを予約しようとした                                  |
| `409`      | `conflict`     | `version` の版が無い、または版の `updated_at` が `version_updated_at` と違う（予約しようとした版が、そのあとの保存で上書きされた）       |

### `DELETE /api/articles/:id/schedule`

記事の予約を取り消す。予約が無くても成功する。記事のイベントの `staff` だけが取り消せる。
サマリーを持つ記事（お知らせ・ブログ・模擬店・出演者）も、このエンドポイントで取り消す。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### パス

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| `id` | `uuid` | ✅   | 記事ID |

#### レスポンス（`200`）

取り消し後の記事オブジェクト（`GET /api/articles/:id` と同じ形）。

#### エラー

| ステータス | `code`         | 条件                                                                                                          |
| ---------- | -------------- | ------------------------------------------------------------------------------------------------------------- |
| `400`      | `bad_request`  | `id` の形式が不正                                                                                             |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効                                                          |
| `403`      | `forbidden`    | 記事のイベントのメンバーだが `staff` でない                                                                   |
| `404`      | `not_found`    | 記事が存在しない、所属していないイベントの記事、または `staff` でないメンバーが下書きの予約を取り消そうとした |

### `PUT /api/articles/:id/tags`

記事に付けるタグをまとめて置き換える。記事のイベントの `staff` だけが変えられる。
1件ずつ足し引きせず、置き換え後の全部を配列で渡す。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### パス

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| `id` | `uuid` | ✅   | 記事ID |

#### リクエストボディ

```json
{
    "tag_ids": ["2a1b3c4d-5e6f-4a7b-8c9d-0e1f2a3b4c5d"]
}
```

| フィールド | 型      | 必須 | 説明                                                     |
| ---------- | ------- | ---- | -------------------------------------------------------- |
| `tag_ids`  | `array` | ✅   | 付けるタグIDの配列。空配列なら全部外す。同じIDは重複不可 |

## お知らせ・ブログ（posts）

お知らせとブログ。サマリーは記事と同じ `id` を持つので、**記事の中身とサマリーをまとめて1つのリソースとして扱う**。
タイトル・本文の正本は記事（`articles`）で、このエンドポイントが一緒に読み書きする。

お知らせとブログは `is_blog` で分ける。持つ情報は同じ。

管理者サイトの個別の編集ページ（お知らせ / ブログ / 模擬店 / 出演者）は、それぞれのエンドポイントを使う。
`/api/articles` を使うのは、サマリーを持たない記事（`slug` 付きの固定ページ）の編集だけ。
ただし予約投稿は種類を問わず `PUT /api/articles/:id/schedule` を使う。

### お知らせ・ブログオブジェクト

記事オブジェクト（[記事（articles）](#記事articles)）のフィールドに加えて、次を持つ。

| フィールド     | 型               | 説明                                               |
| -------------- | ---------------- | -------------------------------------------------- |
| `is_blog`      | `boolean`        | ブログなら `true`、お知らせなら `false`            |
| `committee_id` | `uuid \| null`   | 投稿者の委員会。未選択なら `null`                  |
| `committee`    | `object \| null` | 投稿者の委員会（`id` / `name`）。未選択なら `null` |
| `image_url`    | `string \| null` | 一覧に出すサムネイル。本文に置く画像とは別         |
| `excerpt`      | `string \| null` | 一覧に出す抜粋                                     |

一覧では本文を返さないため、`content` と `latest_history` を除いた形になる（記事と同じ）。

### `GET /api/posts`

#### ヘッダー

| 名前            | 必須 | 説明                                   |

| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### クエリ

| `event_id` | `uuid`    | ✅   | 対象のイベント                           |
| `is_blog`  | `boolean` |      | 指定するとお知らせだけ・ブログだけに絞る |
| `tag_id`   | `uuid`    |      | 指定したタグが付いているものだけに絞る   |
| `limit`    | `number`  |      | 1〜100。既定値 `20`                      |
| `offset`   | `number`  |      | 0以上。既定値 `0`                        |

#### レスポンス（`200`）

```json
{
    "items": [
        {
            "id": "7f1c2a9e-3b4d-4e5f-8a6b-1c2d3e4f5a6b",
            "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
            "title": "模擬店の整理券について",
            "status": "published",
            "published_at": "2026-06-06T13:10:00+09:00",
            "is_blog": false,

            "excerpt": null,
            "tags": [{ "id": "2a1b3c4d-5e6f-4a7b-8c9d-0e1f2a3b4c5d", "name": "模擬店" }]
        }
    ],
    "limit": 20,
    "offset": 0

```

イベントの `staff` には下書きを含むすべてを、それ以外のメンバーには公開済みだけを返す（記事と同じ）。

| ---------- | -------------- | ---------------------------------------------------- |
| `400`      | `bad_request`  | クエリが不正                                         |

| `is_blog`      | `boolean`        |      | 省略すると `false`（お知らせ）                               |
| `committee_id` | `uuid \| null`   |      | 投稿者の委員会。省略すると `null`                            |
| `image_url`    | `string \| null` |      | サムネイルのURL。省略すると `null`                           |
| `excerpt`      | `string \| null` |      | 抜粋。200文字まで。省略すると `null`                         |
| `tag_ids`      | `array`          |      | 付けるタグIDの配列。省略すると空                             |

作成者（`created_by`）はリクエストしたユーザーになり、下書き（`status` が `draft`）で作られる。どちらもボディでは指定できない。

#### レスポンス（`201`）

作ったお知らせ・ブログオブジェクト。

#### エラー

| ステータス | `code`         | 条件                                                                  |
| ---------- | -------------- | --------------------------------------------------------------------- |
| `400`      | `bad_request`  | ボディが不正                                                          |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効                  |
| `403`      | `forbidden`    | そのイベントの `staff` でない                                         |
| `404`      | `not_found`    | `committee_id` / `tag_ids` に違うイベントのもの、存在しないものがある |

### `PUT /api/posts/:id`

お知らせ・ブログを保存する。**記事の保存とサマリーの更新を1回で行う。**
版の残し方・公開状態の決まりは `PUT /api/articles/:id` と同じ。記事のイベントの `staff` だけが保存できる。

#### リクエストボディ

`POST /api/posts` から `event_id` を除き、`status`（`draft` / `published`。省略すると公開状態を変えない）を足したもの。

#### レスポンス（`200`）

保存後のお知らせ・ブログオブジェクト。

#### エラー

`PUT /api/articles/:id` と同じ。`committee_id` / `tag_ids` が不正なときは `404`。

### `DELETE /api/posts/:id`

お知らせ・ブログを消す。**記事（`articles`）と版も一緒に消える。** 記事のイベントの `staff` だけが消せる。

#### レスポンス（`204`）

ボディなし。

#### エラー

| ステータス | `code`         | 条件                                                 |
| ---------- | -------------- | ---------------------------------------------------- |
| `400`      | `bad_request`  | `id` の形式が不正                                    |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効 |
| `403`      | `forbidden`    | 記事のイベントのメンバーだが `staff` でない          |
| `404`      | `not_found`    | 存在しない、または所属していないイベントのもの       |

### `GET /api/posts/:id/adjacent`

前後のお知らせ・ブログ。独自コンポーネント `adjacentPosts` が読む。
同じ `is_blog` のもののうち、公開日時が1つ古いもの・1つ新しいものを返す。

#### レスポンス（`200`）

```json
{
    "previous": { "id": "7f1c2a9e-3b4d-4e5f-8a6b-1c2d3e4f5a6b", "title": "1つ古いお知らせ" },
    "next": null
}
```

無ければ `null`。公開済みのものだけを対象にする。

#### エラー

`GET /api/posts/:id` と同じ。

### `GET /api/posts/:id/related`

関連するお知らせ・ブログ。独自コンポーネント `relatedPosts` が読む。

#### クエリ

| 名前    | 型       | 必須 | 説明              |
| ------- | -------- | ---- | ----------------- |
| `limit` | `number` |      | 1〜10。既定値 `4` |

#### レスポンス（`200`）

```json
{
    "items": [
        {
            "id": "8a2d3b0f-4c5e-4f6a-9b7c-2d3e4f5a6b7c",
            "title": "準備期間の裏側をのぞいてみた",
            "image_url": "https://example.com/thumb.jpg",
            "published_at": "2026-06-02T18:30:00+09:00"
        }
    ]
}
```

同じタグが付いているものを、公開日時の新しい順に返す。自分自身は含めない。抜粋・投稿者は返さない。

#### エラー

`GET /api/posts/:id` と同じ。

## 模擬店（shops）

模擬店。お知らせ・ブログと同じく、**記事の中身とサマリーをまとめて1つのリソースとして扱う**。
店名は記事のタイトル、紹介の本文は記事の本文（`content`）が正本。

### 模擬店オブジェクト

記事オブジェクト（[記事（articles）](#記事articles)）のフィールドに加えて、次を持つ。

| フィールド     | 型               | 説明                                                 |
| -------------- | ---------------- | ---------------------------------------------------- |
| `event_day_id` | `uuid`           | 出店する日（`event_days.id`）                        |
| `event_day`    | `object`         | 出店する日（`id` / `day` / `date`）                  |
| `place_id`     | `uuid \| null`   | 出店する場所。未設定なら `null`                      |
| `place`        | `object \| null` | 出店する場所（`id` / `name` / `building` / `floor`） |
| `group_name`   | `string`         | 出している団体（`2年1組` など）                      |
| `description`  | `string`         | 紹介文。書式なしの文章                               |
| `image_url`    | `string \| null` | サムネイル                                           |
| `color`        | `string`         | カードの色。`rose` / `amber` / `emerald` / `sky`     |
| `starts_at`    | `string \| null` | 開始時刻。未設定なら `null`                          |
| `ends_at`      | `string \| null` | 終了時刻。未設定なら `null`                          |
| `products`     | `array`          | 商品（下表）。`sort_order` の順。無ければ空配列      |

一覧でも `products` は返す（カードの中に商品を出すため）。本文（`content`）と `latest_history` は一覧では返さない。

#### `products`

| フィールド   | 型               | 説明                        |
| ------------ | ---------------- | --------------------------- |
| `id`         | `uuid`           | 商品ID                      |
| `name`       | `string`         | 商品名                      |
| `price`      | `number`         | 価格（円）                  |
| `image_url`  | `string \| null` | 商品の画像。無ければ `null` |
| `sort_order` | `number`         | 並び順                      |

### `GET /api/shops`

模擬店の一覧。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### クエリ

| 名前           | 型       | 必須 | 説明                                   |
| -------------- | -------- | ---- | -------------------------------------- |
| `event_id`     | `uuid`   | ✅   | 対象のイベント                         |
| `event_day_id` | `uuid`   |      | 指定した日のものだけに絞る             |
| `tag_id`       | `uuid`   |      | 指定したタグが付いているものだけに絞る |
| `q`            | `string` |      | 店名・団体名・紹介文の部分一致で絞る   |
| `sort`         | `string` |      | `starts_at`（既定）/ `name`            |
| `limit`        | `number` |      | 1〜100。既定値 `20`                    |
| `offset`       | `number` |      | 0以上。既定値 `0`                      |

#### レスポンス（`200`）

`items` / `limit` / `offset`。`items` は模擬店オブジェクトの配列。
イベントの `staff` には下書きを含むすべてを、それ以外のメンバーには公開済みだけを返す。

#### エラー

`GET /api/posts` と同じ。

### `GET /api/shops/:id`

模擬店1件。記事の中身（`content`）も返す。エラーは `GET /api/posts/:id` と同じ。

### `POST /api/shops`

模擬店を作る。記事・版1・サマリーを1トランザクションで作る。そのイベントの `staff` だけが作れる。

#### リクエストボディ

```json
{
    "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
    "title": "レモネードスタンド",
    "content": [],
    "event_day_id": "1d2e3f4a-5b6c-4d7e-8f9a-0b1c2d3e4f5a",
    "place_id": "3a4b5c6d-7e8f-4a9b-8c0d-1e2f3a4b5c6d",
    "group_name": "2年1組",
    "description": "手しぼりのレモネードを出します。",
    "image_url": null,
    "color": "rose",
    "starts_at": "2026-06-06T09:40:00+09:00",
    "ends_at": "2026-06-06T15:00:00+09:00",
    "tag_ids": []
}
```

| フィールド     | 型               | 必須 | 説明                                     |
| -------------- | ---------------- | ---- | ---------------------------------------- |
| `event_id`     | `uuid`           | ✅   | 対象のイベント                           |
| `title`        | `string`         | ✅   | 店名。100文字まで                        |
| `content`      | `array`          | ✅   | BlockNoteのブロック配列。空配列可        |
| `event_day_id` | `uuid`           | ✅   | 出店する日                               |
| `place_id`     | `uuid \| null`   |      | 出店する場所。省略すると `null`          |
| `group_name`   | `string`         | ✅   | 50文字まで                               |
| `description`  | `string`         | ✅   | 500文字まで。空文字可                    |
| `image_url`    | `string \| null` |      | サムネイルのURL。省略すると `null`       |
| `color`        | `string`         | ✅   | `rose` / `amber` / `emerald` / `sky`     |
| `starts_at`    | `string \| null` |      | 開始時刻。省略すると `null`              |
| `ends_at`      | `string \| null` |      | 終了時刻。`starts_at` より前にはできない |
| `tag_ids`      | `array`          |      | 付けるタグIDの配列。省略すると空         |

商品は作ったあとに `PUT /api/shops/:id/products` で入れる。

#### レスポンス（`201`）

作った模擬店オブジェクト。

#### エラー

`POST /api/posts` と同じ。`event_day_id` / `place_id` / `tag_ids` に違うイベントのもの、存在しないものがあるときは `404`。

### `PUT /api/shops/:id`

模擬店を保存する。記事の保存とサマリーの更新を1回で行う。版の残し方・公開状態は `PUT /api/articles/:id` と同じ。
ボディは `POST /api/shops` から `event_id` を除き、`status` を足したもの。レスポンスは保存後の模擬店オブジェクト。

### `DELETE /api/shops/:id`

模擬店を消す。記事・版・商品も一緒に消える。レスポンスは `204`。エラーは `DELETE /api/posts/:id` と同じ。

### `GET /api/shops/:id/products`

模擬店の商品一覧。`sort_order` の順。

#### レスポンス（`200`）

```json
{
    "items": [
        {
            "id": "9b0c1d2e-3f4a-4b5c-8d6e-7f8a9b0c1d2e",
            "name": "レモネード",
            "price": 300,
            "image_url": null,
            "sort_order": 0
        }
    ]
}
```

### `PUT /api/shops/:id/products`

模擬店の商品をまとめて置き換える。1件ずつ作り消しせず、置き換え後の全部を配列で渡す。
渡した順が `sort_order` になる。模擬店のイベントの `staff` だけが変えられる。

#### リクエストボディ

```json
{
    "items": [{ "name": "レモネード", "price": 300, "image_url": null }]
}
```

| フィールド          | 型               | 必須 | 説明                                     |
| ------------------- | ---------------- | ---- | ---------------------------------------- |
| `items`             | `array`          | ✅   | 商品の配列。空配列なら全部消す。50件まで |
| `items[].name`      | `string`         | ✅   | 50文字まで                               |
| `items[].price`     | `number`         | ✅   | 0以上の整数                              |
| `items[].image_url` | `string \| null` |      | 商品の画像。省略すると `null`            |

#### レスポンス（`200`）

置き換え後の商品一覧（`GET /api/shops/:id/products` と同じ形）。

#### エラー

`PUT /api/articles/:id/tags` と同じ。

## スケジュール（schedules）

タイムテーブル。表示を切り替える単位が開催日（Day1 / Day2）なので、**取得も開催日の単位**で行う。

### `GET /api/schedules/:day`

1日ぶんのタイムテーブル。列と、列ごとの項目をまとめて返す。

#### ヘッダー

| 名前            | 必須 | 説明                                   |
| --------------- | ---- | -------------------------------------- |
| `Authorization` | ✅   | `Bearer <Supabase のアクセストークン>` |

#### パス

| 名前  | 型     | 必須 | 説明                        |
| ----- | ------ | ---- | --------------------------- |
| `day` | `uuid` | ✅   | 開催日ID（`event_days.id`） |

#### レスポンス（`200`）

```json
{
    "day": {
        "id": "1d2e3f4a-5b6c-4d7e-8f9a-0b1c2d3e4f5a",
        "day": 1,
        "date": "2026-06-06",
        "name": null
    },
    "columns": [
        {
            "id": "4c5d6e7f-8a9b-4c0d-8e1f-2a3b4c5d6e7f",
            "name": "体育館",
            "sort_order": 0,
            "events": [
                {
                    "id": "6e7f8a9b-0c1d-4e2f-8a3b-4c5d6e7f8a9b",
                    "name": "オープニング",
                    "description": null,
                    "href": null,
                    "artist_id": null,
                    "starts_at": "2026-06-06T08:20:00+09:00",
                    "ends_at": "2026-06-06T09:20:00+09:00"
                }
            ]
        }
    ]
}
```

列は `sort_order` の順、項目は `starts_at` の順。列に項目が無ければ `events` は空配列。

#### エラー

| ステータス | `code`         | 条件                                                   |
| ---------- | -------------- | ------------------------------------------------------ |
| `400`      | `bad_request`  | `day` の形式が不正                                     |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効   |
| `404`      | `not_found`    | 開催日が存在しない、または所属していないイベントのもの |

### `POST /api/schedules/columns`

列を作る。そのイベントの `staff` だけが作れる。

#### リクエストボディ

| フィールド     | 型       | 必須 | 説明                        |
| -------------- | -------- | ---- | --------------------------- |
| `event_day_id` | `uuid`   | ✅   | どの日の列か                |
| `name`         | `string` | ✅   | 列の名前。30文字まで        |
| `sort_order`   | `number` |      | 0以上の整数。省略すると `0` |

列の名前は場所（`places`）を参照せず、自由に決める。

#### レスポンス（`201`）

作った列（`id` / `event_day_id` / `name` / `sort_order` / `created_at` / `updated_at`）。

#### エラー

`POST /api/event-days` と同じ（`409` は無い）。

### `PUT /api/schedules/columns/:id`

列を更新する。ボディは `POST /api/schedules/columns` から `event_day_id` を除いたもの。日は変えられない。
レスポンスは更新後の列。

### `DELETE /api/schedules/columns/:id`

列を消す。**その列の項目も一緒に消える。** レスポンスは `204`。

### `POST /api/schedules/events`

項目を作る。そのイベントの `staff` だけが作れる。

#### リクエストボディ

```json
{
    "schedule_column_id": "4c5d6e7f-8a9b-4c0d-8e1f-2a3b4c5d6e7f",
    "name": "オープニング",
    "description": null,
    "href": null,
    "artist_id": null,
    "starts_at": "2026-06-06T08:20:00+09:00",
    "ends_at": "2026-06-06T09:20:00+09:00"
}
```

| フィールド           | 型               | 必須 | 説明                                           |
| -------------------- | ---------------- | ---- | ---------------------------------------------- |
| `schedule_column_id` | `uuid`           | ✅   | どの列に置くか                                 |
| `name`               | `string`         | ✅   | 項目の名前。50文字まで                         |
| `description`        | `string \| null` |      | 詳細に出す説明。500文字まで。省略すると `null` |
| `href`               | `string \| null` |      | 押したときの移動先。省略すると `null`          |
| `artist_id`          | `uuid \| null`   |      | 紐付ける出演者。省略すると `null`              |
| `starts_at`          | `string`         | ✅   | 開始時刻                                       |
| `ends_at`            | `string`         | ✅   | 終了時刻。`starts_at` より前にはできない       |

#### レスポンス（`201`）

作った項目。

#### エラー

`POST /api/event-days` と同じ（`409` は無い）。`artist_id` が違うイベントのもの、存在しないものなら `404`。

### `PUT /api/schedules/events/:id`

項目を更新する。ボディは `POST /api/schedules/events` と同じ形（`schedule_column_id` を渡すと別の列へ移す）。
レスポンスは更新後の項目。

### `DELETE /api/schedules/events/:id`

項目を消す。レスポンスは `204`。

## 下のナビゲーション（bottom_navs）

ウェブアプリの下のナビゲーションバーの項目。

### `GET /api/bottom-navs`

イベントのナビの項目一覧。`sort_order` の順（左から）。

#### クエリ

| 名前       | 型     | 必須 | 説明           |
| ---------- | ------ | ---- | -------------- |
| `event_id` | `uuid` | ✅   | 対象のイベント |

#### レスポンス（`200`）

```json
{
    "items": [
        {
            "id": "7a8b9c0d-1e2f-4a3b-8c4d-5e6f7a8b9c0d",
            "label": "お知らせ",
            "icon": "Bell",
            "href": "/news",
            "sort_order": 1
        }
    ]
}
```

#### エラー

`GET /api/event-days` と同じ。

### `PUT /api/bottom-navs`

ナビの項目をまとめて置き換える。1件ずつ作り消しせず、置き換え後の全部を配列で渡す。
渡した順が `sort_order` になる。そのイベントの `staff` だけが変えられる。

#### リクエストボディ

```json
{
    "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
    "items": [{ "label": "ホーム", "icon": "House", "href": "/" }]
}
```

| フィールド      | 型       | 必須 | 説明                                                       |
| --------------- | -------- | ---- | ---------------------------------------------------------- |
| `event_id`      | `uuid`   | ✅   | 対象のイベント                                             |
| `items`         | `array`  | ✅   | 項目の配列。空配列なら全部消す。5件まで                    |
| `items[].label` | `string` | ✅   | 10文字まで                                                 |
| `items[].icon`  | `string` | ✅   | lucide のアイコン名。取りうる値は `packages/schema` で持つ |
| `items[].href`  | `string` | ✅   | `/` で始まるパス。100文字まで                              |

#### レスポンス（`200`）

置き換え後の項目一覧（`GET /api/bottom-navs` と同じ形）。

#### エラー

| ステータス | `code`         | 条件                                                 |
| ---------- | -------------- | ---------------------------------------------------- |
| `400`      | `bad_request`  | ボディが不正、または `icon` が定義にない名前         |
| `401`      | `unauthorized` | `Authorization` ヘッダーがない、またはトークンが無効 |
| `403`      | `forbidden`    | そのイベントの `staff` でない                        |
