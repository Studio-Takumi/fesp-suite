# API仕様

## 記事（articles）

### 記事オブジェクト

| フィールド   | 型       | 説明                                               |
| ------------ | -------- | -------------------------------------------------- |
| `id`         | `uuid`   | 記事ID                                             |
| `event_id`   | `uuid`   | 所属するイベント                                   |
| `content`    | `array`  | BlockNoteのブロック配列（`articleDocumentSchema`） |
| `created_at` | `string` | 作成日時                                           |
| `updated_at` | `string` | 更新日時                                           |

一覧では本文を返さないため、`content` を除いた形になる。

### `GET /api/articles`

イベントの記事一覧。`updated_at` の新しい順。

#### クエリ

| 名前       | 型       | 必須 | 説明                |
| ---------- | -------- | ---- | ------------------- |
| `event_id` | `uuid`   | ✅   | 対象のイベント      |
| `limit`    | `number` |      | 1〜100。既定値 `20` |
| `offset`   | `number` |      | 0以上。既定値 `0`   |

#### レスポンス（`200`）

```json
{
    "items": [
        {
            "id": "7f1c2a9e-3b4d-4e5f-8a6b-1c2d3e4f5a6b",
            "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
            "created_at": "2026-09-14T10:00:00+09:00",
            "updated_at": "2026-09-14T12:30:00+09:00"
        }
    ],
    "limit": 20,
    "offset": 0
}
```

イベントが存在しないときも `items` が空の `200` を返す。

#### エラー

| ステータス | `code`        | 条件         |
| ---------- | ------------- | ------------ |
| `400`      | `bad_request` | クエリが不正 |

### `GET /api/articles/:id`

記事を1件、本文つきで取得する。

#### パス・クエリ

| 名前       | 場所   | 型     | 必須 | 説明           |
| ---------- | ------ | ------ | ---- | -------------- |
| `id`       | パス   | `uuid` | ✅   | 記事ID         |
| `event_id` | クエリ | `uuid` | ✅   | 対象のイベント |

#### レスポンス（`200`）

```json
{
    "id": "7f1c2a9e-3b4d-4e5f-8a6b-1c2d3e4f5a6b",
    "event_id": "0b7e6d5c-4a3b-4c2d-9e1f-a2b3c4d5e6f7",
    "content": [
        {
            "id": "a1",
            "type": "paragraph",
            "props": { "backgroundColor": "default", "textColor": "default", "textAlignment": "left" },
            "content": [{ "type": "text", "text": "現金のみです。", "styles": {} }],
            "children": []
        }
    ],
    "created_at": "2026-09-14T10:00:00+09:00",
    "updated_at": "2026-09-14T12:30:00+09:00"
}
```

#### エラー

| ステータス | `code`        | 条件                                     |
| ---------- | ------------- | ---------------------------------------- |
| `400`      | `bad_request` | `id` / `event_id` の形式が不正           |
| `404`      | `not_found`   | 記事が存在しない、または別イベントの記事 |

### `POST /api/articles`

記事を作成する。

#### クエリ

| 名前       | 型     | 必須 | 説明           |
| ---------- | ------ | ---- | -------------- |
| `event_id` | `uuid` | ✅   | 対象のイベント |

#### リクエストボディ

```json
{
    "content": []
}
```

| フィールド | 型      | 必須 | 説明                                                         |
| ---------- | ------- | ---- | ------------------------------------------------------------ |
| `content`  | `array` | ✅   | BlockNoteのブロック配列（`articleDocumentSchema`）。空配列可 |

#### レスポンス（`201`）

作成した記事オブジェクト（`GET /api/articles/:id` と同じ形）。

#### エラー

| ステータス | `code`        | 条件                                                        |
| ---------- | ------------- | ----------------------------------------------------------- |
| `400`      | `bad_request` | クエリが不正、または `content` が記事ドキュメントの形でない |
| `404`      | `not_found`   | イベントが存在しない                                        |

### `PUT /api/articles/:id`

記事の本文を丸ごと置き換える。`updated_at` は現在時刻になる。

#### パス・クエリ

| 名前       | 場所   | 型     | 必須 | 説明           |
| ---------- | ------ | ------ | ---- | -------------- |
| `id`       | パス   | `uuid` | ✅   | 記事ID         |
| `event_id` | クエリ | `uuid` | ✅   | 対象のイベント |

#### リクエストボディ

`POST /api/articles` と同じ。

#### レスポンス（`200`）

更新後の記事オブジェクト（`GET /api/articles/:id` と同じ形）。

#### エラー

| ステータス | `code`        | 条件                                                                          |
| ---------- | ------------- | ----------------------------------------------------------------------------- |
| `400`      | `bad_request` | `id` / `event_id` の形式が不正、または `content` が記事ドキュメントの形でない |
| `404`      | `not_found`   | 記事が存在しない、または別イベントの記事                                      |
